# 测试错在哪里（本轮实际输出）

固定7题严格结构正确1题，4道动作题均错。这个模型尚不能替换窗口里的旧模型。

| 原意 | 本轮实际输出 | 结论 |
|---|---|---|
| 不要眨眼或鞠躬，静止 | 不支持；不执行 | 没有乱动，但“不要做”被误解为“做不了” |
| 身体左右交替摇摆 | 不支持；不执行 | 正确 |
| 幅度小一点、速度慢一点，但没指定动作 | 执行歪头 | 错误，缺少动作指代时仍自行选了动作 |
| 眨眼和挥手同时开始 | 不支持；不执行 | 错误，本轮合格训练教材没有挥手 |
| 歪头的同时微笑 | 不支持；不执行 | 错误 |
| 先微笑，再左右张望 | 先生气，再左右张望 | 第一段动作选错 |
| 先点头，再摇头 | 先摇头，再摇头 | 第一段动作选错 |

训练最后一轮在72条教材上结构正确64条，原始执行/不执行类别全72条记住；另外8条受到严格时长语法覆盖不足的影响。但按预先声明的验证集规则实际选中第26轮，它在训练题上结构正确56/72，在验证题上2/8、动作题0/5。没有用测试结果重新选轮次或再训练。

这一轮主要证明了：原先的“永远眨眼”可以训练掉，新参数输出不会因为小于允许时长的停顿而技术失败；但记住教材不代表能理解新的表达和动作组合。本次测试技术错误0/7，不能把它当成语义正确。精确时长绑定只覆盖保守句式，也没有在这7道不含精确时长的测试题上制造得分。

训练72条中的42条是实际视频审核动作样本，另30条是实际语义审核的非执行样本。旧的9轮模型仍在默认服务上运行，没有被本轮替换。
